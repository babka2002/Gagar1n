  # Политика в отношении обработки персональных данных

  [Согласие бланк на обработку ПД](https://new.gagar1n.ru/assets/soglasie-na-obrabotku-persona.pdf).

  ## 1. Общие положения
  1.1. Настоящая политика обработки персональных данных (далее — Политика) составлена в соответствии с требованиями Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных» и определяет порядок обработки персональных данных ООО «ХОРС» (далее — Оператор).  
  1.2. Политика применяется ко всей информации, которую Оператор может получить о посетителях веб-сайта [https://new.gagar1n.ru](https://new.gagar1n.ru).

  ## 2. Основные понятия
  | Термин | Определение |
  |--------|-------------|
  | Автоматизированная обработка | Обработка с использованием средств вычислительной техники |
  | Блокирование данных | Временное прекращение обработки (кроме случаев уточнения данных) |
  | Веб-сайт | Совокупность материалов и программ по адресу [https://new.gagar1n.ru](https://new.gagar1n.ru) |
  | Обезличивание | Действия, делающие невозможным определение принадлежности данных без дополнительной информации |
  | Оператор | Юридическое лицо ООО «ХОРС», организующее обработку данных |
  | Персональные данные | Любая информация, относящаяся к прямо или косвенно определенному или определяемому физическому лицу (субъекту персональных данных) |

  *Полный перечень определений приведен в ст. 3 Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных»*

  ## 3. Права и обязанности Оператора
  ### 3.1. Права:
  - Получать достоверные данные от субъектов
  - Продолжать обработку при отзыве согласия (в установленных законом случаях)
  - Самостоятельно определять меры защиты данных

  ### 3.2. Обязанности:
  - Предоставлять информацию по запросам субъектов
  - Обеспечивать безопасность данных
  - Уничтожать данные при достижении целей обработки
  - Публиковать настоящую Политику
  - Обеспечивать возможность получения согласия на обработку персональных данных, включая использование метрических программ (например, Яндекс.Метрика)

  ## 4. Права и обязанности субъектов данных
  ### 4.1. Права:
  - Получать информацию об обработке своих данных
  - Требовать уточнения/удаления данных
  - Отзывать согласие на обработку
  - Обжаловать действия Оператора

  ### 4.2. Обязанности:
  - Предоставлять достоверные данные
  - Сообщать об изменениях персональных данных

  ## 5. Принципы обработки данных
  1. Законность и справедливость
  2. Ограничение конкретными целями
  3. Соответствие содержания заявленным целям
  4. Актуальность и достоверность данных
  5. Ограниченное хранение

  ## 6. Цели обработки персональных данных
  | Параметр | Описание |
  |----------|-----------|
  | **Цель** | Информирование Пользователя через email-рассылки, предоставление услуг фитнес-центра, анализ поведения пользователей на сайте для улучшения сервиса |
  | **Данные** | ФИО, email, номера телефонов, а также данные, собираемые метрической программой Яндекс.Метрика (IP-адрес, сведения о поведении на сайте, включая просмотренные страницы, время пребывания, действия на сайте) |
  | **Основания** | <ul><li>Уставные документы</li><li>Договоры с субъектами</li><li>ФЗ №149 от 27.07.2006</li><li>Согласие субъекта персональных данных</li></ul> |
  | **Виды обработки** | Сбор, запись, хранение, обезличивание, уничтожение |

  ## 7. Условия обработки
  1. С согласия субъекта, включая согласие на обработку данных через формы на сайте и использование метрической программы Яндекс.Метрика
  2. Для исполнения договора
  3. В публичных интересах
  4. Для осуществления правосудия
  5. При работе с общедоступными данными

  ## 8. Порядок обработки данных
  - Безопасность обеспечивается комплексом организационно-технических мер
  - Передача третьим лицам — только по закону или с согласия субъекта
  - Срок хранения — до достижения целей обработки
  - Актуализация данных через email: [office@new.gagar1n.ru](mailto:office@new.gagar1n.ru) с пометкой «Актуализация персональных данных»
  - На сайте используются формы сбора персональных данных («Оставьте нам сообщение», «Оформи свою выгодную карту», «Успей записаться на первое пробное занятие», «Возникли вопросы? Оставьте свой номер телефона, и мы вам перезвоним»), под которыми размещен бланк «Согласия на обработку персональных данных» с возможностью его просмотра и сохранения в формате PDF
  - На сайте используется метрическая программа Яндекс.Метрика для анализа поведения пользователей. При посещении сайта пользователю отображается всплывающее окно с информацией о сборе данных Яндекс.Метрикой и возможностью дать согласие на обработку таких данных путем проставления отметки

  ## 9. Трансграничная передача
  - Требуется предварительное уведомление уполномоченного органа
  - Необходимо получение сведений от иностранных получателей данных

  ## 10. Конфиденциальность
  - Запрет на раскрытие данных без согласия субъекта
  - Обязанность сотрудников сохранять конфиденциальность

  ## 11. Заключительные положения
  1. Актуальная версия доступна по адресу: [https://new.gagar1n.ru/policy](https://new.gagar1n.ru/policy)
  2. Изменения вступают в силу с момента публикации
  3. По вопросам обработки данных обращаться: [office@gagar1n.ru](mailto:office@gagar1n.ru)
