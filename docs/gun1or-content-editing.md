# Руководство по редактированию контента страницы Gun1or

## Как редактировать блок "Мы гордимся нашими воспитанниками!"

### 1. Войдите в админ-панель Statamic

-   Перейдите по адресу: `http://127.0.0.1:8001/cp`
-   Войдите под своими учетными данными

### 2. Найдите страницу Gun1or

-   В левом меню выберите **Collections** → **Pages**
-   Найдите страницу с названием "Gun1or" или "home"
-   Нажмите на неё для редактирования

### 3. Редактируйте блок достижений

-   Прокрутите до раздела **"Достижения и отзывы"**
-   В поле **"Заголовок блока достижений"** можно изменить текст "Мы гордимся нашими воспитанниками!"
-   В поле **"Достижения воспитанников"** добавьте новые достижения:
    -   Нажмите **"Добавить"** → **"Новая группа достижений"** → **"Достижение"**
    -   Заполните поля:
        -   **"Название достижения"** - например: "Победитель соревнований"
        -   **"Описание достижения"** - подробное описание
        -   **"Иконка"** - можно использовать эмодзи (🏆, 🥇, 🎯) или оставить пустым

### 4. Редактируйте блок отзывов

-   В том же разделе найдите поле **"Заголовок блока отзывов"**
-   Можно изменить текст "вот что говорят о нашем центре клиенты"
-   В поле **"Отзывы клиентов"** добавьте новые отзывы:
    -   Нажмите **"Добавить"** → **"Новая группа отзывов"** → **"Отзыв"**
    -   Заполните поля:
        -   **"Текст отзыва"** - сам отзыв клиента
        -   **"Автор отзыва"** - имя автора (необязательно)

### 5. Сохраните изменения

-   Нажмите кнопку **"Save"** в правом верхнем углу
-   Изменения сразу появятся на сайте

## Примеры заполнения

### Достижение:

-   **Название**: "Победитель городских соревнований"
-   **Описание**: "Наш воспитанник занял первое место в городских соревнованиях по гимнастике среди детей 8-10 лет"
-   **Иконка**: 🏆

### Отзыв:

-   **Текст**: "Отличный центр! Мой ребенок с удовольствием ходит на занятия. Тренеры внимательные и профессиональные."
-   **Автор**: "Анна Петрова"

## Важные замечания

1. **HTML теги**: В некоторых полях можно использовать HTML теги для форматирования
2. **Изображения**: Для достижений можно добавить иконки в виде эмодзи или текста
3. **Количество**: Можно добавить любое количество достижений и отзывов
4. **Порядок**: Элементы отображаются в том порядке, в котором вы их добавили
5. **Значения по умолчанию**: При первом создании страницы уже будут заполнены примеры отзывов и достижений
6. **Fallback**: Если отзывы или достижения не заполнены, будут показаны значения по умолчанию

## Как убрать значения по умолчанию

Если вы хотите убрать все отзывы или достижения по умолчанию:

1. **Для отзывов**: В поле "Отзывы клиентов" нажмите на крестик (❌) рядом с каждым отзывом по умолчанию
2. **Для достижений**: В поле "Достижения воспитанников" нажмите на крестик (❌) рядом с каждым достижением по умолчанию
3. **Добавить свои**: После удаления добавьте свои отзывы и достижения через кнопку "Добавить"
